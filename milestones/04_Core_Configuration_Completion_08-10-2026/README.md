## 1. Implemented Core Services Overview

### A. Layer 2 Switching Framework
- **VLANs Provisioned:** VLAN 10 (Engineering), VLAN 20 (HR), VLAN 30 (Sales), VLAN 40 (Server Farm), VLAN 99 (Management), VLAN 999 (Parking Lot).
- **IEEE 802.1Q Trunking:** Deployed on all inter-switch uplinks and the Core Router link with Native VLAN 999 and restricted allowed VLAN lists (`10,20,30,40,99`).
- **Loop Prevention:** Rapid-PVST+ enabled; `SW1-Dist` designated as Primary Root Bridge (`spanning-tree vlan 10,20,30,40,99 root primary`).

### B. Layer 3 Routing Engine
- **Router-on-a-Stick (ROAS):** `R1-Core` subinterfaces `Gi0/0.10`, `Gi0/0.20`, `Gi0/0.30`, `Gi0/0.40`, and `Gi0/0.99` provide wire-speed inter-VLAN routing.
- **Default WAN Routing:** Static route `ip route 0.0.0.0 0.0.0.0 203.0.113.2` directing outbound traffic to simulated ISP.
- **OSPF Dynamic Routing:** OSPF Process 1 configured in Area 0 covering internal campus subnets with passive interfaces on external links.

### C. Dynamic Network Services
- **Cisco IOS DHCP Server Pools:**
  - `POOL_ENG`: Network `192.168.10.0/24`, Gateway `192.168.10.1`, DNS `192.168.40.10`
  - `POOL_HR`: Network `192.168.20.0/24`, Gateway `192.168.20.1`, DNS `192.168.40.10`
  - `POOL_SALES`: Network `192.168.30.0/24`, Gateway `192.168.30.1`, DNS `192.168.40.10`
  - Excluded Addresses: `.1` through `.9` reserved across all departmental subnets.
- **Central TFTP Server (`192.168.40.10`):** Configured and operational in Server Farm VLAN 40.
