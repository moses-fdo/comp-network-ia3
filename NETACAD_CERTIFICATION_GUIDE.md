## 1. Overview & Official Course Details

The Cisco Networking Academy **"Networking Basics"** course is a free, self-paced certification offering foundational mastery in computer networking, TCP/IP protocols, network media, IP addressing, and basic network troubleshooting. Upon completion, Cisco issues a verified **Credly Digital Badge** and a **Course Certificate of Completion**.

- **Official NetAcad Portal:** [https://www.netacad.com](https://www.netacad.com)
- **Course Title:** *Networking Basics* (formerly part of Cisco CCNA / Skills For All suite)
- **Estimated Completion Time:** 15 – 22 hours
- **Prerequisites:** None (Introductory level)
- **Credential Earned:** Cisco Verified Digital Badge (Credly) & Official PDF Certificate

## 3. Course Curriculum & Exam Preparation Key Points

Review these core topic areas before taking the final exam:

### Module 1: Communication in a Connected World
- Data transmission over networks, client-server models, peer-to-peer networks.
- Bandwidth vs. Throughput vs. Latency.

### Module 2: Network Components & Types
- End devices (hosts), intermediate devices (routers, switches, firewalls, wireless access points), and network media (copper UTP, optical fiber, wireless RF).
- LAN vs. WAN vs. PAN vs. WLAN.

### Module 3: Network Topologies & Access
- Physical vs. Logical topologies (Star, Mesh, Bus, Ring, Hierarchical).
- Ethernet standards (IEEE 802.3), MAC addresses (48-bit hex), frame switching mechanisms.
- Straight-through vs. Crossover vs. Rollover cables.

### Module 4: IP Addressing & Subnetting (High Exam Weight)
- IPv4 address classes (A, B, C, Private ranges RFC 1918):
  - Class A: `10.0.0.0/8`
  - Class B: `172.16.0.0/12`
  - Class C: `192.168.0.0/16`
  - Loopback: `127.0.0.1` | APIPA: `169.254.0.0/16`
- Subnet mask calculations (CIDR notation `/24`, `/28`, `/30`).
- IPv6 fundamentals (128-bit hexadecimal, SLAAC, Link-Local `fe80::/10`).

### Module 5: Transport & Application Layers
- TCP (Connection-oriented, reliable, 3-way handshake SYN-SYN/ACK-ACK, sequence numbers) vs. UDP (Connectionless, best-effort, low overhead, VoIP, DNS, TFTP).
- Well-known port numbers:
  - TFTP: `UDP 69`
  - SSH: `TCP 22`
  - HTTP/HTTPS: `TCP 80` / `TCP 443`
  - DNS: `UDP/TCP 53`
  - DHCP: `UDP 67/68`

### Module 6: Basic Network Security & Troubleshooting
- Strong password enforcement, AAA, SSH encryption over insecure Telnet.
- Diagnostic utilities: `ping` (ICMP echo request/reply), `traceroute` / `tracert` (TTL decrement), `ipconfig` / `ifconfig`, `netstat`.
